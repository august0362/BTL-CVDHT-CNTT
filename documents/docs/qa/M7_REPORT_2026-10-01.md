# M7 Multi-Face Support — QA Report (2026-10-01)

## Verdict: PASS

This report records acceptance of the original ADR-023 scope (20-face cap and opt-in expander) only. ADR-024 later expanded M7 to a 30-face cap, pre-inference single/multi routing, a card grid, a details route, and radar removal; that expanded scope still requires separate verification. The original multi-face flow passed a real local smoke with RealESRGAN x4v3, YOLO26-face, CodeFormer, WSL2 EMOCA, and CPU MA3D-Net. It makes no claim that restoration improves emotion accuracy.

## Environment and real-model run

| Component | Environment / evidence |
|---|---|
| Web | Windows, Python 3.13.5, PyTorch 2.14.0 CPU |
| EMOCA | WSL2 Ubuntu 22.04, Python 3.8, PyTorch 1.11.0, CUDA 11.5; NVIDIA RTX 3050 Laptop 4 GB; real service contract 0.3.0 |
| Models | RealESRGAN `realesr-general-x4v3`, YOLO26-face, CodeFormer, EMOCA `EMOCA_v2_lr_mse_20`, POSTER and MA3D RAF-DB checkpoints; both engine checkpoints loaded strict with 1369 keys |
| Input | Two local RAF-DB test crops resized and composed in memory into one 340×180 image; blank and one-face inputs were also processed in memory. No composite, crop, or result image was written. |

| Case | Result |
|---|---|
| Baseline on the uploaded 340×180 image | POSTER and MA3D both returned valid predictions. A second baseline inference after the opt-in flow kept both top labels; maximum probability difference was 0.0 in the final rerun (acceptance tolerance 1e-5). The Streamlit test also confirms the cached primary result is exactly unchanged after the multi-face button is used. |
| One face | Real RealESRGAN + YOLO returned one face; the optional path returned `kind=single` and no extra MA3D rows. 1.548 s in the final acceptance run. |
| No faces | Both YOLO passes found none; real CodeFormer ran on the full image; EMOCA returned `no_face`; the untouched image was retried and also returned `no_face`. Both attempts remained visible. 10.781 s. |
| Two faces | IDs 1 and 2 were assigned top-to-bottom, then left-to-right. Original-image boxes: `(6, 11, 164, 168)` and `(178, 12, 327, 157)`. CodeFormer returned 188×180 and 185×179 crops; MA3D returned valid top-1 predictions (`surprise`, 0.6970; `sadness`, 0.8912). No preprocessing errors. 30.605 s. |
| Resource sample | Web process RSS: 1848.6 MB before the M7 run, 2040.6 MB sampled peak (+192.1 MB). EMOCA health reported 1900 MB reserved VRAM peak and 1174.2 MB free after the run. Total acceptance script time: 61.230 s. |

The two-face and one-face inputs used the project's local RAF-DB test samples. The no-face input was a generated blank image. All image processing stayed on the local Windows/WSL2 stack.
